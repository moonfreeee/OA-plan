## 1. 软件概述

本系统是一套基于 Web 的办公室内部管理平台，用于统一管理成员信息、团队项目、日常打卡、周期性考核、内部培训课程与公告通知。用户通过浏览器访问，无需安装客户端。

**主要功能**：
- 用户登录与密码找回
- 首页仪表盘与每日打卡
- 个人中心（信息维护、修改密码）
- 考核成绩查询（支持时间筛选）
- 团队管理与任务看板
- 课程学习与进度跟踪
- 管理员后台（账号、公告、团队、考核、课程、打卡）

## 3. 软件安装说明

### 3.1 获取源代码

从 GitHub 克隆或下载项目：

```
https://github.com/moonfreeee/OA-plan.git
```

切换到开发分支（如需要最新功能）：

```powershell
git checkout dev
```

### 3.2 安装数据库

**步骤 1**：打开 SQL Server Management Studio (SSMS)，连接本地 SQL Server 实例。

**步骤 2**：创建数据库：

```sql
CREATE DATABASE SDO_OA;
GO
```

**步骤 3**：在 SSMS 中打开并执行 `database/schema.sql`（创建全部数据表）。

**步骤 4**：配置后端数据库连接。复制 `backend/.env.example` 为 `backend/.env`，填写数据库信息：

```
DB_SERVER=localhost
DB_PORT=1433
DB_NAME=SDO_OA
DB_USER=sa
DB_PASSWORD=你的密码
DB_USE_WINDOWS_AUTH=false
JWT_SECRET=请修改为随机字符串
```

**步骤 5**：写入演示数据（推荐使用 Node 脚本）：

```powershell
cd backend
npm.cmd install
npm.cmd run reset-db
```

执行成功后控制台会提示：`账号: admin / Admin@123 , member1 / Member@123`

### 3.3 安装并启动后端

```powershell
cd backend
npm.cmd install
npm.cmd run dev
```

看到 `SDO OA API running on http://localhost:3000` 表示后端启动成功。

> 若提示端口 3000 被占用，请先关闭旧的后端进程。

### 3.4 安装并启动前端

```powershell
cd frontend
npm.cmd install
npm.cmd run dev
```

看到 `Local: http://localhost:5173/` 表示前端启动成功。

确认 `frontend/.env.development` 中：

```
VITE_USE_MOCK=false
```

### 3.5 访问系统

在浏览器中打开：**http://localhost:5173**

### 3.6 演示模式（无需数据库）

若仅需浏览界面演示，可将 `VITE_USE_MOCK=true`，仅启动前端即可。此时数据为本地模拟，不影响真实数据库。

### 3.7 Windows 常见问题

**问题**：运行 `npm` 时弹出「选择打开方式」。

**解决**：使用 `npm.cmd` 代替 `npm`，或双击 `frontend/start-dev.bat` / `backend/start-dev.bat`。

## 4. 登录与账号

### 4.1 演示账号

| 用户名 | 密码 | 角色 | 说明 |
|--------|------|------|------|
| admin | Admin@123 | 管理员 | 可使用全部管理功能 |
| member1 | Member@123 | 成员 | 普通成员功能 |
| member2 | Member@123 | 成员 | 普通成员功能 |

### 4.2 登录操作

1. 打开系统地址，进入登录页。
2. 在「用户登录」标签下，输入**用户名或邮箱**及**密码**。
3. 可选勾选「记住账号」，下次自动填充用户名。
4. 点击「登录」按钮。
5. 登录成功后自动跳转至**首页仪表盘**。

### 4.3 密码找回

> 本系统不支持自助重置密码，需提交申请由管理员审核。

1. 在登录页切换到「密码找回」标签。
2. 输入您的**用户名或邮箱**。
3. 输入**新密码**和**确认密码**（至少 6 位）。
4. 点击「提交申请」。
5. 等待管理员在「密码找回审核」中批准后，使用新密码登录。

### 4.4 退出登录

点击页面右上角用户头像旁的下拉菜单，选择「退出登录」。

## 6. 功能操作指南

### 6.1 首页仪表盘

**界面组成**：
- 欢迎卡片：头像、姓名、所属团队/课程/考核摘要
- **打卡按钮**：每日打卡一次
- 统计卡片：团队数、进行中课程、待完成考核、公告数
- 公告列表：最新公告
- 近期动态：考核、任务、学习进度更新

**每日打卡步骤**：
1. 登录后默认进入首页。
2. 在欢迎卡片区域找到「打卡」按钮。
3. 点击「打卡」。
4. 提示「打卡成功」后，按钮变为不可点击状态。
5. 同一自然日内不可重复打卡。

---

### 6.2 个人中心

**路径**：左侧菜单 → 个人中心

**修改个人信息**：
1. 在表单中修改姓名、手机、头像 URL、个人简介。
2. 点击「保存」。

**修改密码**：
1. 输入当前密码（旧密码）。
2. 输入新密码（至少 6 位）。
3. 点击「修改密码」。

**查看摘要**：页面下方展示最近考核均分与课程学习进度概览。

---

### 6.3 考核系统

**路径**：左侧菜单 → 考核系统

**查询历史成绩**：
1. 在顶部筛选栏选择**年**、**月**（可选）、**日**（可选）。
2. 点击「查询」。
3. 下方显示符合条件的考核周期与已发布成绩。
4. 每条成绩展示技术、协作、态度、贡献四维分数及综合均分、评语。

> 仅显示管理员已**发布**的成绩；未发布或进行中的考核可能无成绩记录。

---

### 6.4 我的团队

**路径**：左侧菜单 → 我的团队

**查看所属团队**：
- 以卡片形式展示您已加入的团队。
- 点击卡片进入**团队详情**。

**加入其他团队**：
1. 点击「添加其他项目团队 +」进入**项目团队总览**。
2. 浏览全部团队列表。
3. 对未加入的团队点击「申请加入」。
4. 等待管理员审核通过后，团队出现在「我的团队」中。

**团队详情页**（点击团队卡片进入）：
- 查看团队名称、项目描述、负责人。
- 查看成员列表。
- 使用**三列任务看板**（待办 / 进行中 / 已完成）管理团队任务。
- 可点击「申请退出团队」提交退出申请。

**任务操作**（团队成员）：
- 负责人或管理员可创建新任务。
- 被指派者可更新任务状态（如从「待办」拖至「进行中」）。

---

### 6.5 课程学习

**路径**：左侧菜单 → 课程学习

**学习课程**：
1. 在课程列表中查看各课程的分类、难度与学习进度百分比。
2. 点击课程卡片进入**课程详情**。
3. 在章节列表中点击章节阅读内容。
4. 学习完成后点击「标记完成」。
5. 进度条自动更新。

---

### 6.6 管理员 — 账号管理

**路径**：系统管理 → 账号管理

**创建新成员**：
1. 点击「新建账号」。
2. 填写用户名、密码、真实姓名、联系方式、邮箱、学号。
3. 点击「确定」。
4. 新成员可使用所设用户名和密码登录。

**编辑成员**：点击列表中「编辑」，修改姓名、联系方式等信息。

**删除成员**：点击「删除」，确认后移除（不可删除管理员账号）。

---

### 6.7 管理员 — 密码找回审核

**路径**：系统管理 → 密码找回审核

1. 查看待审核的密码找回申请列表。
2. 点击「通过」：成员新密码立即生效。
3. 点击「拒绝」：申请作废，成员需重新提交。

---

### 6.8 管理员 — 公告管理

**路径**：系统管理 → 公告管理

**发布公告**：
1. 点击「新建公告」。
2. 填写标题与内容。
3. 点击「发布」。
4. 公告将出现在所有用户的首页公告列表中。

**编辑/删除**：在列表中对已有公告进行操作。

---

### 6.9 管理员 — 团队管理

**路径**：系统管理 → 团队管理

**创建团队**：
1. 点击「新建团队」。
2. 填写团队名称、描述，可选指定负责人。
3. 保存后可手动添加成员。

**审核申请**：
- 切换「加入申请」「退出申请」标签页。
- 对 pending 状态的申请点击「通过」或「拒绝」。

---

### 6.10 管理员 — 考核管理

**路径**：系统管理 → 考核管理

**创建考核周期**：
1. 点击「新建周期」。
2. 填写周期名称、开始日期、结束日期、状态（草稿/进行中/已结束）。
3. 保存。

**录入成绩**：
1. 选择某一考核周期。
2. 为成员填写技术、协作、态度、贡献四维分数（0–100）及评语。
3. 点击「保存」。

**发布成绩**：
1. 在成绩列表中对某条记录点击「发布」。
2. 发布后成员方可在「考核系统」中查看。

---

### 6.11 管理员 — 课程管理

**路径**：系统管理 → 课程管理

**创建课程**：
1. 点击「新建课程」。
2. 填写标题、分类、描述、难度、状态。
3. 保存后可为课程添加章节。

**管理章节**：
1. 进入课程详情。
2. 添加章节：填写标题、内容（支持 Markdown）、排序、时长。
3. 可编辑或删除已有章节。

---

### 6.12 管理员 — 打卡详情

**路径**：系统管理 → 打卡详情

1. 页面顶部显示今日**应到人数**、**已打卡**、**未打卡**统计。
2. 下方表格列出全部 active 成员的打卡状态与打卡时间。
3. 已打卡成员排在前面，未打卡显示「未打卡」。

## 7. 常见问题（FAQ）

| 问题 | 解决方法 |
|------|----------|
| 登录提示「无法连接后端服务」 | 确认 backend 已启动（`npm.cmd run dev`），SQL Server 已运行 |
| 登录提示「账号待审核」 | 联系管理员在账号管理中审核通过 |
| 忘记密码 | 在登录页「密码找回」提交申请，联系管理员审核 |
| 看不到「系统管理」菜单 | 仅 admin 角色可见，请使用管理员账号登录 |
| 考核页查不到成绩 | 确认管理员已录入并**发布**成绩；检查筛选日期是否正确 |
| 打卡按钮无法点击 | 表示今日已打卡，次日零点后方可再次打卡 |
| 页面显示乱码 | 运行 `npm.cmd run reset-db` 重建数据库 |
