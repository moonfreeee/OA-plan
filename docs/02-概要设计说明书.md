# 概要设计说明书

## 1. 系统架构

本系统采用 B/S 三层架构：

```
表现层（Vue 3 + Element Plus）
    ↓ HTTP/JSON
业务层（Node.js Express API）
    ↓ mssql
数据层（Microsoft SQL Server）
```

## 2. 部署图

```
[浏览器 Chrome/Edge] --HTTP:5173--> [Vite Dev Server / Nginx 静态资源]
                                          |
                                    proxy /api
                                          |
                                    [Express :3000]
                                          |
                                    [SQL Server :1433]
```

## 3. 组件划分

### 3.1 前端组件

| 模块 | 组件/页面 | 职责 |
|------|-----------|------|
| 认证 | LoginView, RegisterView, ResetPasswordView | 登录注册 |
| 布局 | MainLayout | 顶栏+侧栏导航 |
| 业务 | DashboardView, ProfileView, AssessmentView, TeamsView, CourseDetailView | 业务页面 |
| 管理 | admin/*View | 管理员 CRUD |
| 公共 | api/request.js, stores/user.js | HTTP 与状态 |

### 3.2 后端模块

| 模块 | 路由文件 | 职责 |
|------|----------|------|
| 认证 | routes/auth.js | 注册登录重置 |
| 用户 | routes/users.js | 个人信息与审核 |
| 仪表盘 | routes/dashboard.js | 统计数据 |
| 公告 | routes/announcements.js | 公告 CRUD |
| 团队 | routes/teams.js | 团队与任务 |
| 考核 | routes/assessments.js | 周期与成绩 |
| 课程 | routes/courses.js | 课程章节进度 |

## 4. 接口规范

- 协议：HTTP/HTTPS
- 格式：JSON
- 前缀：`/api/v1`
- 认证：`Authorization: Bearer <token>`
- 响应：`{ code: 0, message: "ok", data: {} }`

## 5. 数据库概要

共 11 张表，详见 `database/schema.sql`。

## 6. 安全设计

- JWT 有效期 24 小时
- bcrypt 密码哈希（cost=10）
- 角色中间件 requireRole('admin')
- 前端路由 meta.roles 二次校验

## 7. UI 设计

- 登录页：居中卡片式
- 主界面：顶栏 + 左侧 220px 菜单 + 内容区
- 任务看板：三列 Kanban 布局
- 配色：Element Plus 默认蓝主题
