# 详细设计说明书

## 1. 类图（≥9 类）

| 类名 | 属性 | 方法 |
|------|------|------|
| User | userId, username, email, role, status | login(), updateProfile() |
| AuthService | jwtSecret | register(), login(), resetPassword() |
| Team | teamId, teamName, leaderId | addMember(), removeMember() |
| TeamTask | taskId, title, status | updateStatus() |
| AssessmentPeriod | periodId, title, status | activate(), close() |
| AssessmentScore | scoreId, techScore, teamScore... | calculateAvg(), publish() |
| Course | courseId, title, category | addChapter() |
| CourseChapter | chapterId, title, content | markComplete() |
| Announcement | announcementId, title, content | publish(), delete() |
| DashboardService | - | getSummary(), getActivities() |

## 2. 顺序图：用户登录流程

```
用户 -> LoginView: 输入账号密码
LoginView -> API: POST /auth/login
API -> Users表: 查询用户
API -> bcrypt: 验证密码
API -> jwt: 生成 Token
API -> LoginView: 返回 token + user
LoginView -> Pinia: setAuth()
LoginView -> Router: 跳转 /dashboard
```

| | |
|---|---|
| 输入 | user_id, chapter_id |
| 处理 | INSERT LearningProgress（幂等） |
| 输出 | 完成标记 + 重新计算 progress_pct |

## 5. 关键算法

**课程完成率** = 已完成章节数 / 总章节数 × 100%

**考核平均分** = (tech + team + attitude + contribution) / 4
