## 1. 测试计划

### 1.1 测试目标

验证系统各功能模块符合项目规格说明书要求，确保登录认证、业务 CRUD、权限控制、打卡与审核流程在真实后端联调环境下正常工作。

### 1.2 测试策略

| 阶段 | 内容 |
|------|------|
| 静态分析 | 代码审查、SQL 参数化检查、路由权限配置检查 |
| 模块测试 | 逐模块验证 API 请求与响应 |
| 集成测试 | 前端 → Vite 代理 → Express → SQL Server 全链路 |
| 系统测试 | 按用户角色模拟完整业务流程 |

### 1.3 测试范围

- 用户认证（登录、密码找回申请）
- 账号管理（管理员 CRUD、密码找回审核）
- 首页仪表盘（统计、公告、动态、打卡）
- 个人中心（信息编辑、改密、摘要）
- 考核系统（时间轴筛选、成绩查看、管理端录入发布）
- 团队管理（我的团队、总览、加入/退出申请、任务看板）
- 课程学习（列表、章节完成、进度）
- 公告管理
- 管理端打卡详情
- 权限控制（成员不可访问管理页）

## 5. 源代码运行结果说明

### 5.1 后端健康检查

**请求**：`GET http://localhost:3000/api/v1/health`

**响应**：
```json
{
  "code": 0,
  "message": "ok",
  "data": { "status": "healthy" }
}
```

### 5.2 登录接口

**请求**：`POST /api/v1/auth/login`
```json
{ "account": "admin", "password": "Admin@123" }
```

**响应**（节选）：
```json
{
  "code": 0,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "user_id": 1,
      "username": "admin",
      "role": "admin",
      "status": "active",
      "real_name": "系统管理员"
    }
  }
}
```

### 5.3 仪表盘统计

**请求**：`GET /api/v1/dashboard/summary`（带 Token）

**响应 data 结构**：
```json
{
  "stats": {
    "teamCount": 1,
    "courseInProgress": 2,
    "pendingAssessment": 1,
    "announcementCount": 3
  },
  "announcements": [ /* 最新 5 条 */ ],
  "activities": [ /* 最近 10 条动态 */ ]
}
```

**member1 登录后页面表现**：欢迎卡片显示姓名"张三"；统计卡片数值与 API 一致；公告列表展示 3 条种子公告。

### 5.4 打卡功能

**请求**：`POST /api/v1/dashboard/clock-in`

**首次响应**：
```json
{
  "code": 0,
  "message": "打卡成功",
  "data": { "clockedIn": true, "clockInTime": "2026-06-16T09:30:00.000Z" }
}
```

**重复请求响应**：
```json
{ "code": 1, "message": "今日已打卡", "data": null }
```

**管理端** `GET /dashboard/clock-in/today` 返回 `clocked_count`、`absent_count` 及全员明细表，与 `ClockInView.vue` 展示一致。

### 5.5 考核时间轴筛选

**请求**：`GET /api/v1/assessments/my-scores?year=2025&month=6`

**结果**：返回 2025 春季考核成绩，四维分数 tech=88, team=90, attitude=92, contribution=85，avg_score=88.75。前端 `AssessmentView.vue` 时间轴与成绩卡片正常渲染。

### 5.6 团队加入申请

**操作流程**：
1. member1 访问 `/teams/overview`，对「NFC硬件制作组」点击申请加入
2. 提示"加入申请已提交，请等待管理员审核"
3. admin 在 `/admin/teams` 加入申请标签页批准
4. member1 刷新「我的团队」，可见新团队卡片

**数据库验证**：`TeamMembershipRequests` 状态变为 `approved`；`TeamMembers` 新增对应记录。

### 5.7 权限控制

**操作**：member1 浏览器地址栏输入 `http://localhost:5173/admin/accounts`

**结果**：自动重定向至 `/dashboard`，管理页面不可访问。

## 8. 已知限制

1. 密码找回需管理员人工审核，无真实邮件通知。
2. 课程内容为 Markdown 文本，不支持多媒体上传。
3. 列表接口无分页，大数据量场景未测试。
4. 测试在本地单机环境进行，未覆盖生产部署与并发压力测试。
