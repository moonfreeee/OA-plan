# 软件测试分析报告

## 1. 测试计划

### 1.1 测试目标

验证系统各功能模块符合需求规格，确保登录、业务 CRUD、权限控制正常工作。

### 1.2 测试策略

- 静态分析：代码审查、SQL 参数化检查
- 动态测试：模块测试 → 集成测试 → 系统功能测试

### 1.3 测试环境

- OS：Windows 10/11
- 浏览器：Chrome / Edge
- 后端：Node.js 18+, Express, localhost:3000
- 数据库：SQL Server + seed 演示数据
